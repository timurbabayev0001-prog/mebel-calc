# МебельКальк · версия 0.1

Веб-приложение на русском языке для расчёта корпуса шкафа или тумбы. Работает на HTML, CSS и JavaScript, без сервера, базы данных, внешних библиотек и подключения к интернету.

## Как открыть

1. Скачайте проект с GitHub: зелёная кнопка **Code → Download ZIP** (выберите ветку с версией 0.1).
2. Распакуйте архив.
3. Откройте файл `index.html` в Chrome, Edge, Firefox или другом современном браузере.

Установка программ и сборка не требуются. Укажите размеры в миллиметрах и выберите толщину ЛДСП. Результат обновляется автоматически; кнопка «Рассчитать корпус» также запускает проверку.

## Проверка результата

Введите ширину **800**, высоту **720**, глубину **500**, выберите ЛДСП **16 мм**:

| Деталь | Размер, мм | Количество |
| --- | --- | --- |
| Боковина | 720 × 500 | 2 |
| Верх и низ | 768 × 500 | 2 |

С толщиной 18 мм верх и низ должны стать **764 × 500 мм**. Очистите любое поле или введите отрицательное число: появится объяснение ошибки, а спецификация скроется. При исправлении числа расчёт появится снова.

## Android

Интерфейс рассчитан на узкие экраны от 320 пикселей, поля вызывают цифровую клавиатуру. Для удобного открытия на телефоне можно разместить эти статические файлы на GitHub Pages. Публикация не включена автоматически.

Для проверки через локальную сеть (если на компьютере установлен Python):

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

Запустите команду в папке проекта. Подключите телефон и компьютер к одной Wi-Fi сети и откройте на телефоне `http://IP-КОМПЬЮТЕРА:8080`. Разрешите доступ в локальной сети, если его запросит система. Остановите сервер сочетанием Ctrl+C. Этот сервер нужен только для просмотра файлов, приложение не имеет серверной логики.

## Правила расчёта

- Две боковины: наружная высота × глубина.
- Верх и низ между боковинами: (наружная ширина − 2 × толщина ЛДСП) × глубина, всего две детали.
- Толщина ЛДСП: 16 или 18 мм.
- Размеры — положительные целые миллиметры. Ширина и высота должны быть больше двух толщин ЛДСП, чтобы внутри оставалось пространство. Числа должны находиться в безопасном целочисленном диапазоне JavaScript.
- Размеры без припусков, учёта кромки, крепежа и технологических зазоров.

Фасады, полки, задняя стенка и 3D в версии 0.1 не рассчитываются.

## Структура и автоматические тесты

- `index.html` — интерфейс.
- `styles.css` — оформление и адаптация к мобильным экранам.
- `calculator.js` — расчёт и проверка размеров.
- `app.js` — обновление интерфейса.
- `tests/calculator.test.cjs` — проверки расчёта и ошибок.

Если установлен Node.js 18 или новее:

```sh
node --test tests/calculator.test.cjs
```

Для запуска самого приложения Node.js не нужен.
