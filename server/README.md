# Стоимость кухни и корпуса · закрытый прайс

Node.js 18+, без зависимостей. `/` — корпус с вращаемой 3D-моделью, `/kitchen/` — кухня, `/owner` — владелец. Публичный `/api/quote` отдаёт только одну ориентировочную сумму с точностью до гяпика, валюту AZN и признак неучтённых расходов. Прайс и подробная смета требуют входа. Публичная стоимость не округляется до сотен и не превращается в диапазон.

## Windows: пробный запуск

Распакуйте весь архив. Рядом должны находиться папки `mebel-calc` и `private`. Откройте `mebel-calc/start-local.cmd` двойным щелчком, задайте пароль от 16 символов (ввод скрыт). Файл использует Node.js и штатный PowerShell, не меняет политики выполнения. Браузер откроется автоматически; если сервер ещё запускается, обновите страницу. Ссылки: `http://localhost:8080/kitchen/`, `http://localhost:8080/`, `http://localhost:8080/owner`. Окно запуска оставьте открытым. Остановка: Ctrl+C. При повторном запуске можно задать новый пароль; прайс сохранится.

Если старый сервер уже работает на 8080, сначала остановите его Ctrl+C. Новый архив распакуйте в **отдельную папку**, чтобы сохранить прежний проект и прайс. Если вы уже редактировали цены на своём компьютере, скопируйте свой старый `private/prices.json` в новую папку `private` перед запуском; старый формат поддерживается. Не теряйте сохранённые проекты JSON; они открываются в новой версии.

## Сервер

Прайс JSON хранится **за пределами публичного каталога**, на постоянном диске. `PRICE_FILE` — полный путь к файлу, серверу нужны права записи в его папку. `OWNER_PASSWORD` — секрет от 16 символов. Пароль в Git не записывается. Из корня проекта:

```sh
node server/server.cjs
```

`LOCAL_HTTP=1` используется только локально: сервер слушает 127.0.0.1, cookie без Secure. В интернете не задавайте эту переменную: нужен HTTPS-прокси с сохранением исходного Host, cookie Secure/HttpOnly/SameSite=Strict. Сессия — час, после перезапуска требуется вход. Лимит входов — 20 попыток в минуту на весь экземпляр. Одно приложение с одним постоянным диском. GitHub Pages серверный код не запускает, публикация на текущем сайте не выполнена. Для интернет-версии нужен HTTPS-хостинг Node.js и постоянный диск. Секреты не отправлять в чат или GitHub.

## Прайс владельца

40 шаблонных наименований фурнитуры/крепежа/подсветки, 26 дополнительных статей: кромка, присадка, фрезеровка, вырезы, дополнительные материалы, упаковка, расходники, замер, доставка, подъём, монтаж. Можно добавлять и удалять свои строки. Пустая цена — неизвестна, ноль — бесплатно. Фурнитура оплачивается только в количестве из спецификации и по точному названию (основные названия крепежа корпуса нормализуются). Смена единицы цены не пересчитывает физические единицы автоматически: единица должна соответствовать выбранному способу количества.

Дополнительная статья должна быть явно включена. Автоколичество: длина кромки, длина столешницы, число деталей, один раз на заказ. Ручное количество: владелец сохраняет проект кухни или корпуса из калькулятора, загружает в панели, задаёт метры реза, отверстия, вырезы, рейсы и т. п. и пересчитывает. Нулевое количество означает, что операция не требуется. Ручные количества не хранятся в глобальном прайсе и не передаются клиентом: публичная сумма такие статьи помечает как неучтённые. Они доступны только в расчёте владельца; автоматического переноса сметы заказа клиенту пока нет.

Распил: выбирается **либо за лист, либо за метр реза**, не оба. Метров реза без карты раскроя нет, их вводит владелец. Кромка: либо объединённая цена за метр, либо две строки «материал» и «наклейка». Распил по листам учитывает ЛДСП; раскрой ХДФ при необходимости добавляйте отдельной ручной статьёй.

ЛДСП и фасады: количество целых листов оценивается по площади отдельно для каждого декора и толщины с запасом. Это **не точная раскладка деталей**. Листы не считаются поштучно для каждого модуля: материалы группируются по всему проекту. Цена ЛДСП 18 мм и столешницы 40 мм применяется к остальным толщинам с явным предупреждением, что соответствующий прайс не задан. Другие материалы не исчезают из предупреждений. Работа и наценка — процент от всех учтённых расходов. Не включайте сборку/монтаж повторно, если они уже входят в надбавку. Владелец видит материалы/обработку, надбавку и итог отдельно; клиент — только итог.

Направляющие оцениваются комплектом на ящик. Геометрия ящика остаётся существующей, для боковых направляющих; под скрытый монтаж нужна документация конкретной модели и отдельная корректировка конструкции. 3D корпуса показывает геометрию рассчитанных стенок, секций, полок, дверей и деревянных ящиков. Дополнительные детали и фурнитура не размещаются автоматически. Это визуализация, не производственный чертёж.

## Проверки

```sh
node --test tests/*.test.cjs
```

Браузерная проверка: кухня и корпус возвращают одну сумму; неверные размеры скрывают устаревшую цену; 3D меняет изображение при повороте; вход/сохранение/выход владельца; загрузка проекта корпуса в смету. Приватный прайс находится вне Git и архива исходников в GitHub.
