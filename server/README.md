# Пробный расчёт кухни и закрытый прайс

Node.js 18+; сторонних зависимостей нет. Сервер отдаёт существующую версию 0.5 по `/kitchen/`, панель владельца по `/owner`. Публичный API `/api/quote` возвращает только диапазон в AZN и признак неполного расчёта. Прайс и подробный расчёт требуют входа. Пароль задаётся через секрет `OWNER_PASSWORD` (от 16 символов), не хранится в репозитории. Это вход по паролю, без email и восстановления доступа.

## Запуск

Храните JSON прайса **за пределами репозитория и публичного каталога**, на постоянном диске. Переменная `PRICE_FILE` должна указывать на этот файл; серверу нужны права записи в его папку. Исходный прайс владельца подготовлен отдельно, не включён в Git. Структуру полей описывает `fields` в `pricing.cjs`; `hardware` содержит дополнительные цены по точным названиям из спецификации. Не публикуйте приватный файл или резервную копию в GitHub.

Из корня проекта, с настроенными переменными:

```sh
node server/server.cjs
```

Для локальной проверки разрешается `LOCAL_HTTP=1`; в интернете не задавайте эту переменную. Публикуйте сервер за HTTPS-прокси с сохранением исходного Host. По умолчанию cookie Secure, HttpOnly, SameSite=Strict, время сессии один час. Пароль вводится только на `/owner`; цены редактируются формой и сохраняются на диск. Для проверки подробной суммы сохраните кухню в JSON через существующую кнопку и загрузите её в панели владельца. При перезапуске нужно снова войти. Лимит входов: 20 попыток в минуту на весь экземпляр.

Этот вариант предполагает один сервер и один постоянный диск. GitHub Pages серверный код не выполняет: текущая опубликованная ссылка пока не получает цены. Для рабочего публичного варианта нужен HTTPS-хостинг Node.js с постоянным диском; можно перенести сайт целиком, сохранив интерфейс. Отдельное подключение API к GitHub Pages потребует настройки адреса API и CORS, которой здесь нет. Автоматическая публикация не выполнена.

## Правила

ЛДСП и фасады: оценка количества целых листов по площади отдельно для каждого декора и толщины, плюс процент запаса. Это приблизительная оценка, без раскладки деталей и учёта пропила. Распил оплачивается за каждый оценённый лист. Столешница — по длине в метрах. Направляющие — комплект на ящик. Работа и наценка — процент от учтённых материалов, фурнитуры и распила, отдельной строкой владельцу. Клиенту выдаётся только диапазон от общей суммы, округлённый наружу заданным шагом. Неизвестные цены помечаются как неучтённые; публичная оценка имеет предупреждение. Ноль означает бесплатную позицию, null означает отсутствие цены. Применение прайса 18 мм к другим толщинам явно помечается как неполный расчёт.

Направляющие оцениваются комплектом скрытого монтажа, но конструкция ящика остаётся существующей: размеры и сверление нужно согласовать с конкретной моделью направляющих. Кромка, ХДФ, ручки, крепёж и подсветка требуют отдельных цен. Нет стоимости техники, доставки, замера, налогов и инженерных коммуникаций.
